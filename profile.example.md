# Your ADHD coach profile (optional)

Everything in this plugin works with **zero setup**. This file only exists to make the
output sharper and stop the skills re-asking the same questions.

**How to use it:** copy this, fill in what's true for you, delete what isn't, and either
paste it into the conversation, save it somewhere your client can read, or store it in
your client's memory feature if it has one. Nothing here is required — partial is fine.
