# ADHD Coach

An ADHD-informed coaching plugin for AI agents. It diagnoses what's *actually* blocking you — a dopamine dip, burnout, boredom, initiation resistance, missing urgency — and delivers the matching intervention, instead of generic productivity advice.

Works in GitHub Copilot CLI, Claude Code, and other clients that support [Agent Plugins 1.0](https://agent-plugins.org/).

**I am not a clinician.** I have no training in psychology, psychiatry, medicine, counselling, or any related field. I'm a software engineer who built a set of prompts that work for my own ADHD brain, and published them in case they're useful to someone else.

**This is a personal project shared as-is.** It is not a medical device, not a therapeutic tool, not a clinical instrument, and has not been reviewed or validated by any professional or institution.

**This plugin does not diagnose anything.** Where it uses words like "diagnose" or "burnout," it means a rough coaching read from a simple framework — nothing more. Low motivation and fatigue can be caused by depression, anxiety, sleep disorders, thyroid problems, medication issues, grief, and plenty else. An AI following a prompt file cannot tell those apart. A qualified professional can.

**Nothing here substitutes for real care.** If you're struggling, please talk to a doctor, therapist, or psychiatrist. This plugin is not a replacement for diagnosis, therapy, medication management, or professional ADHD support.

**This runs on an AI, and AI output needs reviewing.** Everything this plugin produces is generated by a large language model following a prompt. LLMs confidently state things that are wrong, invent detail, miss context you thought was obvious, and vary run to run — the same question can yield different advice on different days. Treat every response as a suggestion from a well-read stranger who doesn't know you, not as an authoritative answer.

In practice that means: read the output before acting on it, sanity-check anything with real consequences, and ignore advice that doesn't fit your situation, your body, your finances, or your life. Be especially careful with anything involving money, public commitments, deadlines you tell other people about, or a decision to quit something that matters — the plugin will suggest these and it has no idea what's actually at stake for you. **You are the one making the decision. The AI is not accountable for it, and neither am I.**

## What's in it

One router skill plus seven interventions. In normal use you only invoke the router — it asks 1–3 questions, works out what's going on, and runs the right intervention in the same turn.

| Skill | What it does |
|---|---|
| **`adhd-coach`** | The router. Diagnoses and delivers. **Start here.** |
| `adhd-dopamine-menu` | A menu of quick, healthy stimulation options to reach for instead of scrolling — under 2 min, 10 min, and 30 min |
| `adhd-task-unstick` | Three concrete tactics to start a specific task your brain keeps refusing |
| `adhd-task-reframe` | Reconnects an avoided task to something you genuinely care about, and turns it into a game |
| `adhd-reward-system` | A start / midpoint / finish reward structure timed for how ADHD reinforcement actually works |
| `adhd-motivation-diagnose` | Distinguishes a dopamine dip from burnout from genuine loss of interest — they need opposite responses |
| `adhd-routine-refresh` | Four variations of a recurring task so your brain keeps treating it as novel |
| `adhd-manufactured-urgency` | Real external stakes you can set up in 30 minutes, for when nothing starts without a deadline |

Each intervention also works standalone if you already know what you need.

## Install

### GitHub Copilot CLI

```bash
copilot plugin marketplace add timothymeyers/adhd-coach
copilot plugin install adhd-coach@adhd-coach
```

<sub>A direct `copilot plugin install timothymeyers/adhd-coach` also works today, but Copilot has deprecated direct repo/path installs in favour of marketplace installs — prefer the two-step form above.</sub>

### Claude Code

```bash
/plugin marketplace add timothymeyers/adhd-coach
/plugin install adhd-coach@adhd-coach
```

### Other Agent Plugins 1.0 clients

Clone the repo and point your client at the directory, or follow its plugin-install instructions for a git source.

```bash
git clone https://github.com/timothymeyers/adhd-coach.git
```

## Use it

Just describe what's going on. The router handles the rest.

```
/adhd-coach I've been avoiding the quarterly report for three days
```

```
/adhd-coach I keep picking up my phone every ten minutes
```

```
/adhd-coach I used to love this side project and now I feel nothing about it
```

You can also call an intervention directly:

```
/adhd-task-unstick I need to start the migration script
```

### Invocation differs slightly by client

| Client | Form |
|---|---|
| **Copilot CLI** | `/adhd-coach` |
| **Claude Code** | `/adhd-coach:adhd-coach` (plugin name prefixes the skill name) |
| **Others** | Check how your client surfaces plugin skills |

In Claude Code the interventions are likewise `/adhd-coach:adhd-task-unstick`, and so on.

## Personalization (optional)

Everything works with **zero setup** — the skills ask for what they need in the moment.

If you want sharper output, keep a short profile of what you care about, what constraints you have, and which rewards actually land. See [`profile.example.md`](./profile.example.md) for a template. Paste it in, keep it somewhere your client can read, or store it in your client's memory if it has one.

The plugin never requires a profile and never writes one for you.

## Design principles

These skills are opinionated. They assume:

1. **Willpower isn't the answer.** The ADHD brain discounts future rewards and struggles with initiation. Interventions lower initiation cost or raise immediate salience — they don't demand more effort.
2. **Novelty, challenge, and urgency are the three levers.** Nearly everything reduces to one of them.
3. **Immediate beats big.** A small reward in minutes outperforms a large one in days.
4. **Real stakes beat internal promises.** Anything living only in your head gets renegotiated by the same brain that's already stuck.
5. **Rest is an intervention, not a failure.**
6. **Sometimes the honest answer is "quit this."** Loyalty to dead projects burns years.

The tone is deliberately direct — coach, not cheerleader. No hype, no exclamation points as motivation, no "you've got this."
